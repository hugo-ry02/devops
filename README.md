# DevOps Course Repository

Ce dépôt contient les travaux pratiques et projets du cours DevOps.

## Prérequis et environnement

Les outils suivants sont configurés :
- **Docker** : cluster & containers
- **kind** : cluster Kubernetes local
- **kubectl** : CLI Kubernetes
- **Helm** : gestionnaire de paquets Kubernetes
- **OpenTofu / Terraform** : Infrastructure as Code (IaC)
- **kubeseal** : chiffrement des secrets Kubernetes
- **Git** : gestion de versions
